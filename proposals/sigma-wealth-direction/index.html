Inspiration

The moving background behind the headline duplicates Valence Financial's atmospheric WebGL cloud-field hero: the technique of a slow, soft, drifting gradient instead of a static stock photo. We rebuilt it as a lightweight canvas animation in your own navy/sage/gold palette rather than copying their code.

Animation style

Ambient, not flashy. Three colour blobs drift on independent slow paths (a full cycle takes 60 to 90 seconds), so it reads as atmosphere you notice over time, not a spectacle competing with the headline. This mirrors Valence's own restraint: motion in the background, stillness in the foreground text.

Type style

A clean modern sans for everything, with exactly one word per headline breaking into a warm italic serif, the same device Valence uses ("one step ahead"). Small, deliberate, not decorative.

Logo

From a raster image to a real typographic mark

Your current logo is a flattened PNG with no vector source, so it can't scale cleanly or adapt to dark and light sections. Direction: replace it with a real typographic wordmark that carries the same accent-serif device used throughout the page, so it works everywhere the current image can't.
